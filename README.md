# Agentic AI & GitHub Copilot (Free Plan) – MCP Tooling + C# Hands-on Lab

## Overview
This lab introduces developers to the integration of Agentic AI and GitHub Copilot using MCP tooling in a hands-on environment. Participants will learn how to utilize Copilot's capabilities effectively within Visual Studio Code while developing in C#.

## Outcomes
By the end of this lab, students will be able to:
- Utilize GitHub Copilot for code suggestions and improvements.
- Implement and run C# code in a Linux container environment.
- Configure Azure Function endpoints for MCP tooling.

## Constraints (Copilot Free limits)
Please note that the free plan of GitHub Copilot has certain limitations:
- Limited access to advanced features.
- Specific usage caps on suggestions per session.

## Prerequisites
- A GitHub account.
- VS Code installed on your Linux container desktop.
- Basic understanding of C# programming.

## Time-boxed Agenda (60 min lab inside a 2-hour session)
- **Introduction (10 min)**: Overview of the lab's goals.
- **Setup (15 min)**: Signing in and setting up the environment.
- **Hands-on development (30 min)**: Code implementation with GitHub Copilot's guidance.
- **Q&A session (5 min)**: Addressing queries and sharing insights.
